Privacy Policy

DSH Calendar · Last updated 19 November 2026

What this application is

DSH Calendar is a private, single-user desktop tool that connects to Google Calendar so its owner can read upcoming events and create or modify their own events using natural language. It runs entirely on the owner's own computer. It is not a public service, has no other users, and offers no accounts or sign-up.

What Google data it accesses

After you grant consent through Google's own OAuth 2.0 screen, the application may access:

  • Calendar events on your own calendar accounts (titles, times, descriptions, locations, attendees, and recurrence information) — to display and manage them.
  • The ability to create, update, and delete events on your behalf, and to read free/busy availability, at your explicit request.

It requests no other Google data. It does not access Gmail, Drive, Contacts, or any other Google service unless you separately authorize that service.

Where your data goes

Nowhere else. Data retrieved from Google is used only on the local machine to answer your requests and to perform the calendar operations you ask for. The application sends data only to Google's own API endpoints. It contains no analytics, no telemetry, no advertising, and no third-party servers.

Your calendar data is never sold, rented, or shared with any third party.

Storage and retention

  • An OAuth refresh token is stored locally on your computer so the tool does not ask you to sign in each time. It is not transmitted anywhere else.
  • Calendar information is processed in memory. Any local copies are caches created at your request and can be deleted at any time.
  • No cloud storage, database, or backup service is operated by this application.

Deleting your data and revoking access

You can revoke this application's access at any time:

  • Visit myaccount.google.com/permissions and remove the app's access. Revocation takes effect immediately and invalidates the stored refresh token.
  • Delete the local token directory on your computer to remove the stored credential.

Since no data is held on any server, removing local files and revoking access leaves nothing behind on any system other than Google's own account data, which you control.

Google API Limited Use disclosure

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used only to provide the calendar features described above, is not transferred to others except as necessary to provide those features or as required by law, and is not used for advertising or for training generalized artificial-intelligence models.

Security

Access is governed by Google's OAuth 2.0 authorization flow, and the application never sees your Google password. The local credential file is protected by your operating system's user account permissions.
